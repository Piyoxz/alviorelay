Panduan Cara Pasang & Integrasi Client SDK

Langkah mudah menghubungkan aplikasi web Anda ke AlvioRelay SFU

Instalasi Paket Web SDK

Gunakan package manager favorit Anda di project frontend (React, Next.js, Vue, Svelte, atau Vanilla Vite):

# Menggunakan npm
npm install @alviorelay/client

# Menggunakan yarn
yarn add @alviorelay/client

# Menggunakan pnpm
pnpm add @alviorelay/client

Catatan: Web SDK berukuran kecil (< 20 KB), zero heavy dependencies, dan kompatibel penuh dengan modern ES Modules.

Inisialisasi & Bergabung ke Ruangan

Buat instance AlvioRoom dan daftarkan event listener siklus hidup ruangan:

import { AlvioRoom } from '@alviorelay/client';

const room = new AlvioRoom();

// Tangani event saat berhasil terhubung ke server
room.on('connected', ({ peerId, nodeId }) => {
  console.log(`Terhubung ke Alvio node: ${nodeId}, Peer ID: ${peerId}`);
  // Gabung ke ruangan target
  room.join('ruang-rapat-dev', 'Budi Developer');
});

// Tangani peserta lain bergabung
room.on('peerJoined', (peer) => {
  console.log(`Peserta masuk: ${peer.name}`);
});

// Mulai koneksi WebSocket ke AlvioRelay Gateway
await room.connect('wss://relay.domainanda.com/ws');

Publikasi Kamera, Mikrofon, dan Simulcast Layer

Dapatkan stream dari kamera/mikrofon browser dan publikasikan ke SFU dengan dukungan multi-layer simulcast adaptif:

// 1. Ambil stream lokal browser
const stream = await navigator.mediaDevices.getUserMedia({
  audio: true,
  video: { width: 1280, height: 720 }
});

// 2. Publikasikan Audio
const audioTrack = stream.getAudioTracks()[0];
await room.publishTrack(audioTrack, { source: 'microphone' });

// 3. Publikasikan Video Kamera dengan Simulcast (High, Med, Low)
const videoTrack = stream.getVideoTracks()[0];
await room.publishTrack(videoTrack, {
  source: 'camera',
  simulcast: true,
  layers: ['low', 'medium', 'high']
});

// 4. Beralih kualitas dinamis untuk menghemat bandwidth
await room.setPreferredLayer('trk_video_123', 'low'); // 180p
await room.setPreferredLayer('trk_video_123', 'high'); // 720p

Kanal Data SCTP (Chat & Telemetri Sub-10ms)

Kirim pesan broadcast atau titik ke titik (unicast) dengan opsi reliable atau lossy streaming:

// Mengirim pesan obrolan (Reliable SCTP)
await room.sendData(JSON.stringify({ text: 'Halo tim!' }), {
  reliable: true
});

// Mengirim posisi kursor whiteboard (Unreliable lossy ultra-low-latency)
await room.sendData(JSON.stringify({ x: 520, y: 310 }), {
  reliable: false
});

// Menerima pesan dari peserta lain
room.on('dataReceived', ({ sourcePeerId, payload }) => {
  const data = JSON.parse(payload);
  console.log(`Pesan dari ${sourcePeerId}:`, data);
});
